Website and web application development for e-commerce businesses

Most e-commerce businesses already have a storefront on Shopify, WooCommerce, or BigCommerce, so website work for them is rarely about building a store from scratch. It is more often about what sits around the store: a wholesale ordering portal for retail accounts, a product configurator for made-to-order items, a returns request form that feeds ShipStation, or a separate brand site that links to the shop. Some businesses also need a staff-facing application for tasks the store platform does not cover.

Creosote Labs builds those customer-facing tools and web applications and connects them to the store, the shipping software, and the accounting file the business already uses. A project begins with a scoping call, after which we quote a fixed price with no hourly billing. We handle hosting setup and domain configuration, test the finished tool against real orders, and hand it over with written documentation so staff can maintain it without us.

What we do

  • Marketing websites with clear services, pricing, and a way to book or contact the business.
  • Customer-facing tools such as quote requests, bookings, intake forms, and portals.
  • Web applications that replace manual processes for staff and customers.
  • Hosting setup, domain configuration, and handover with documentation.

Common projects

  • A wholesale portal where retail accounts log in, see their negotiated pricing, and place orders that land in the same fulfillment queue.
  • A product configurator that lets customers choose size, material, and finish for made-to-order items and sends the spec with the order.
  • A returns request form that checks the order number, applies the return policy, and creates the label in ShipStation.
  • A brand site with product stories, stockist locations, and a press page that links to the existing store.
  • A staff application for kitting and bundling that tracks component stock separately from the sellable SKU.

Frequently asked questions

  • Can the application work with the Shopify store we already have?

  • What do we need to provide before work starts?

    The project needs a scoping call, access to the store and any tools the application will connect to, and the content or business rules the tool depends on, such as wholesale price lists or the return policy.
