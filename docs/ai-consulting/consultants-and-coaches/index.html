AI consulting for consultants and coaches

Many consulting and coaching practices run on a scheduling tool such as Calendly or Acuity, Zoom for sessions, Google Workspace or Microsoft 365 for documents, and QuickBooks or FreshBooks for invoicing. Client records often sit in HubSpot, Dubsado, HoneyBook, or a spreadsheet. Much of the work outside sessions is writing: proposals, statements of work, session notes, progress summaries, and follow-up emails, most of which start from a previous version.

Creosote Labs reviews how a practice currently produces that writing and identifies where an AI tool the practice already has access to, such as Microsoft 365 Copilot, Google Gemini, or Claude, can do the first draft. We set the tool up with the practice's own proposal templates, intake questionnaires, frameworks, and past deliverables, so the output matches how the practice already writes. Then we train the team on their own work and leave a written guide.

What we do

  • Assess current processes and identify where AI tools save time.
  • Set up the tools the business already has access to, such as Microsoft 365 Copilot, Google Gemini, or Claude, with the company's own documents and templates.
  • Automate document preparation, customer communication, and reporting.
  • Train staff on the company's own work, with a written guide for the team.

Common projects

  • A proposal drafting setup that produces a first draft from discovery call notes and the practice's own proposal template.
  • A session summary process that turns a Zoom transcript into client-ready notes and a list of agreed next steps.
  • An intake review step that reads a new client's questionnaire and prepares a briefing before the first session.
  • A quarterly progress report that assembles session notes and milestones into the practice's standard report format.
  • A follow-up email process that drafts check-ins between sessions in the practitioner's own tone.
  • A written assessment of which parts of the practice's non-session work are worth automating and which are not.
