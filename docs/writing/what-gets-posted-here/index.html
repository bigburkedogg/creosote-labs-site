A short note on what this page is for.

Draft — scaffolding, not a finished post. Replace it or finish it, then set draft: false in the front matter.

This is the writing page for Creosote Labs. It holds notes from work in progress: what we built, what we checked, and where we turned out to be wrong.

Three kinds of post:

  • Build notes. Something we made, what it does, and the part that did not work the first time. first build note: name the project and the date
  • Source checks. A claim someone made in public, the source it cites, and what the source actually says.
  • Tools. Things we wrote for our own use and kept using.

Posts go up here first. Some are cross-posted elsewhere; the copy on this page is the archive. Substack URL, once cross-posting is set up
